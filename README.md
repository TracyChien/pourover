# 手沖日報 The Daily Brew

一個報紙風格的手沖咖啡計算器。選好豆款和器具，輸入粉量或水量，就會算出配方、列出分段注水步驟，並用計時器帶你一步步沖完。

整個網站只有一個 `index.html`，不需要安裝、不需要伺服器，用瀏覽器打開就能用。

## 功能

### 選豆與配方
- **四種豆款**：精品莊園豆（藝伎、耶加雪菲）、一般淺焙、中焙、深焙。選好後自動帶入建議水溫、粉水比與沖法。
- **四種沖煮方式**
  - **三段式**：悶蒸、主萃取、收尾，適合所有焙度。
  - **4:6 法**：粕谷哲的沖法，可調整「風味」（偏甜／平衡／偏酸亮）和「濃度」（淡／標準／濃），適合淺焙精品豆。
  - **濾掛**：依水量自動拆成少量多次注水，避免溢出濾袋。
  - **摩卡壺**：選 1／2／3／4／6 杯壺，自動帶入粉量與水量，可加牛奶做成拿鐵（1:2 或 1:3）。
- **冰手沖**：總水量拆成六成熱水沖煮、四成冰塊放在下壺。
- **粉水雙向換算**：輸入粉量或水量其中一個，另一個依比例（1:13–1:17）自動算出。

> 手沖步驟的時間以 V60 錐形濾杯為準；平底濾杯流速較慢，總時間會稍長。

### 沖煮步驟與計時
- 每一段列出開始時間、注水方式，以及**電子秤上應該看到的累計克數**。
- 計時器會標示目前這一段，並顯示下一段還有幾秒、要注到幾克。
- 下一段開始前有 3、2、1 倒數提示音；換段時也會提示。
- **沖煮模式**：全螢幕大字只顯示目標克數、計時和下一步，站在一公尺外也看得清楚。
- 摩卡壺的出液時間取決於爐火，所以改成看狀態按「下一步」，並記下實際時間。
- 計時時會嘗試讓螢幕保持常亮（視瀏覽器是否支援）。

### 品嚐與紀錄
- **風味調整建議**：喝完選感受（剛剛好、偏酸單薄、苦澀、太淡、太濃），會告訴你原因和下一杯該怎麼改。比例的調整可以一鍵套用。
- **沖煮紀錄（我的配方本）**：記下日期時間、配方、感受、1–5 分評分、磨豆機刻度和筆記。每筆紀錄都可以「照這杯再沖」，一鍵帶回當時的配方。
- **匯出 CSV**：把全部紀錄複製成 CSV，貼到試算表保存或分析。

## 使用方式

### 直接打開
下載 `index.html`，用瀏覽器（Chrome、Safari、Edge、Firefox）打開即可。

### 用 GitHub Pages 發布
1. 把 `index.html` 和 `README.md` 推到 GitHub repository。
2. 到 repository 的 **Settings → Pages**。
3. **Source** 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約一分鐘後，網站會出現在 `https://<你的帳號>.github.io/<repository 名稱>/`。

## 資料儲存

沖煮紀錄存在瀏覽器的 `localStorage`，不會上傳到任何伺服器。

- 紀錄只存在你使用的那個瀏覽器。換手機、換電腦，或清除瀏覽器資料後就看不到了。
- 用檔案直接打開和用 GitHub Pages 網址打開，會是兩份不同的紀錄。
- 想長期保留，請定期用「複製紀錄（CSV）」貼到試算表。

## 技術

- 單一 HTML 檔，原生 HTML、CSS、JavaScript，沒有框架也沒有建置步驟。
- 字型來自 Google Fonts：Playfair Display、Lora、Inter、JetBrains Mono，中文使用 Noto Serif TC 與 Noto Sans TC。離線時會改用系統字型，功能不受影響。
- 提示音使用 Web Audio API，需要先按一次「開始計時」才會發聲。

## 設計

採用「Newsprint」報紙版面風格：米白紙色、墨黑文字、只在重點使用的編輯紅；零圓角、明顯的格線、大型襯線標題、首字放大、跑馬燈與反白區塊。手機版會收成單欄，所有按鈕至少 44px 方便點選。

## 免責聲明

水溫、比例、時間與摩卡壺容量都是常見的建議起點，不同的豆子、磨豆機、濾杯和器材都會有差異，請依自己的口味調整。使用摩卡壺時請注意安全：水不要超過安全閥，粉不要壓實，加熱時不要離開爐邊。
